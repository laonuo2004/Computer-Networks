CGI 多线程 Web 服务器

这个页面由自己实现的 HTTP/1.0 服务器通过 TCP socket 返回。服务器使用固定工作线程池，并支持静态资源、CGI、访问日志和连接上限管理。

打开 CGI 计算器 查询学生信息

静态页面

HTML、CSS 和 SVG 文件直接从 webroot 返回，并自动设置 MIME 类型和 Content-Length。

动态页面

表单数据通过 POST 传给独立 CGI 子进程，子进程生成 HTML 响应。

并发处理

主线程只负责接受连接，固定数量的 worker 并行处理浏览器请求。
